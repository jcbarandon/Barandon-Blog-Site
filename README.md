# Barandon Blog Site

A personal blog by Joe Carlo Jr. O. Barandon — thoughts, project updates, and certifications, with posts that can include an image or a PDF attachment.

**Live site:** [barandon-blog-site-se3w.vercel.app](https://barandon-blog-site-se3w.vercel.app)

## Features

- Browse and read posts — public, no account needed
- Posts can include an image or a PDF (PDFs get an auto-generated first-page preview)
- Light/dark theme toggle, remembers your preference
- Publishing and editing is restricted to the site admin

## Tech Stack

- [Express 5](https://expressjs.com/) + [EJS](https://ejs.co/) – server-rendered app
- [MongoDB](https://www.mongodb.com/) + [Mongoose](https://mongoosejs.com/) – database
- [Cloudinary](https://cloudinary.com/) – image/PDF storage and thumbnail generation
- Deployed on [Vercel](https://vercel.com/)
